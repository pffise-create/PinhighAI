# Alki DivotLab Browser Demo

Public URL: https://golfcoachexpofixed--demo.expo.app

## 60-second interview walkthrough

1. Start on the Driver session and explain that DivotLab turns one swing into one clear practice priority.
2. Click Address, Transition, Impact, and Finish to show phase-specific visual coaching. Press Space to play the sequence.
3. Click `What changed from my last driver session?` to show that the coach uses prior-session context rather than analyzing each swing in isolation.
4. Switch to the Wedge session to show that the finding, coach context, prompts, and drill all change together.
5. Click `New analysis` to explain the production upload flow. A local video can be previewed without sending it anywhere.

## Demo behavior

- The browser experience uses curated, deterministic coaching data so it is reliable during a live presentation.
- Local video preview never uploads the selected file.
- Keyboard shortcuts: `1`-`4` select swing phases; Space starts or pauses the phase sequence.
